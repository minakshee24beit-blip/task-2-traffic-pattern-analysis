# Task 2 – Find Patterns in Traffic Data

## Project Overview
This task focuses on analyzing sample website analytics data to identify unusual spikes or drops and understand their possible causes.

## Objective
To explore Google Analytics data, identify three unusual patterns, and present the findings in a structured spreadsheet.

## Tools Used
- Google Analytics 4 (GA4) Demo Account
- Microsoft Excel
- GitHub

## Analysis Performed
- Explored the GA4 analytics report.
- Examined engagement patterns across traffic channels.
- Identified three visible engagement-time spikes:
  1. Organic Social
  2. Organic Shopping
  3. Referral
- Recorded approximate periods and engagement values.
- Documented possible explanations for the observed patterns.

## Deliverables
- `Traffic_Pattern_Analysis_Improved.xlsx` – Excel workbook containing pattern analysis, methodology, definitions, and a traffic-volume findings template.
- `GA4_Traffic_Report.png` – Screenshot evidence of the analytics report (if uploaded).

## Important Note
The initial analysis is based on average session engagement time, not actual traffic volume. The traffic-volume findings sheet requires additional Sessions or Users data to complete the traffic spike/drop analysis.

Possible causes are interpretations and have not been independently verified.

## Conclusion
This task provided practical experience in exploring website analytics, identifying unusual engagement patterns, documenting possible causes, and organizing findings in Excel.
